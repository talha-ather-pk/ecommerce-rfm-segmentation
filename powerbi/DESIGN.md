# Harbor & Pine Executive Dashboard: design and implementation notes

Version 2 of the Power BI report. Everything here is generated by [`scripts/build_pbip.py`](../scripts/build_pbip.py); re-run it after changing the script, then open `HarborPine.pbip` in Power BI Desktop and click **Refresh**.

## 1. What changed from version 1

| Area | Version 1 | Version 2 |
|---|---|---|
| Look and feel | Default Power BI theme, plain cards | Custom theme `theme/HarborPine_Executive.json`: navy / gold palette, rounded cards with soft shadows, consistent titles and subtitles |
| Navigation | Page tabs only | Navy sidebar with brand, page menu (active page highlighted with a gold marker) and all filters in one place |
| Filters | Four slicers repeated across the top of each page; Region and Channel did not affect the RFM page | Four synced dropdown slicers in the sidebar; every slicer now filters every page |
| Header | Static subtitle that went out of date when filtering | Page title plus a live filter line, e.g. `2025 · West · All channels · All segments` |
| KPI cards | Number only | Label, value and a coloured year-over-year line (`▲ 32.2%  2025 vs 2024`); teal = better, terracotta = worse, so "late rate ▼" shows as good |
| Charts | Mostly plain bar charts | Revenue vs prior-year trend (dashed PY line), growth waterfall by category, RF heatmap matrix, carrier × region heatmap, late-rate trend by carrier, revenue-vs-margin scatter, colour-coded scorecards and a ranked product table |
| Interactivity | Cross-filtering only | Drill-through page (**Category Detail**) with back button; report-page tooltip (**Month snapshot**) on trend lines; dynamic chart titles |
| Data model | RFM in its own table linked to both facts; 13 numeric columns summed by default; measures spread over tables | RFM attributes merged onto `dim_customer` (one customer dimension, true star schema); `_Measures` table with display folders; implicit measures disabled; month columns added to `dim_date` |
| Measures | 33 | 121 (68 visible). All 33 originals kept with the same names and results |

## 2. Design system

| Token | Value | Used for |
|---|---|---|
| Navy | `#0B1F3A` | Sidebar, insight panel, dark heat cells |
| Gold | `#C8A24A` | Brand, active-page marker, KPI accent |
| Primary | `#1F4E79` | Main data series |
| Comparison | `#B8C2CF` | Prior year / secondary series (dashed) |
| Good / Warn / Bad | `#0E7C86` / `#D08C2E` / `#B5523B` | Conditional formatting, KPI deltas |
| Canvas | `#F3F5F9` | Page background |
| Type | Segoe UI Semibold (titles, values), Segoe UI (labels) | |

Every visual has a title and a one-line subtitle that states the business question it answers.

Layout grid: 1280 × 720 canvas, 208 px sidebar, content from x = 224 to 1264, 12 px gutters, KPI row at y = 76, two content rows of about 250 px.

## 4. Measures (display folders in `_Measures`)

| Folder | Examples |
|---|---|
| 1 Sales | Revenue, Orders, Customers, Avg Order Value, Revenue PY, Revenue YoY %, Revenue YTD, Revenue Rolling 3M, Revenue Share of Total |
| 2 Customers | Repeat Customers, Repeat Rate %, Came Back % |
| 3 RFM | Scored Customers, Lifetime Revenue, % of Customers, % of Revenue, Avg Lifetime Spend, Top Segments Revenue Share |
| 4 Delivery | Late Rate %, Avg Delivery Days, Avg Review Score, Low Reviews %, Payment Mismatches |
| 5 Products | Item Revenue, Item Revenue PY, Gross Margin %, Units Sold, Category Revenue Share, Product Rank |
| 6 Year over year | `<KPI> vs PY`, `<KPI> vs PY Label` for 13 KPIs, Item Revenue Change vs PY |
| 7 Dynamic text | Filter Context, Title Trend, Title Waterfall, Title Category, Title Tooltip |
| 8 Formatting (hidden) | Review / Late / Margin / YoY colours, Late Heat, RF Heat |
| 9 Helpers (hidden) | Selected Year, note texts |

**How the year-over-year tiles work.** `Selected Year = MAX(dim_date[year])` picks the latest year in the current filter. `<KPI> (Latest Year)` and `<KPI> (Prior Year)` evaluate the KPI for that year and the one before, so the label always says exactly which years it compares. With 2023 selected it shows "No prior year to compare". Rates use percentage-point changes; delivery days and review scores use absolute changes.

**Checked against the SQL output:** revenue $4,687,356.64, 44,468 orders, 29,459 customers, 2025 vs 2024 revenue +32.2%, 2024 vs 2023 +55.0%, segment shares, late rate 13.2%, low-review share 5.0%.

## 5. Using it

* **Navigate:** sidebar menu. In Power BI Desktop hold **Ctrl** and click; in the Power BI Service a plain click works.
* **Drill through:** right-click a category in the scatter, scorecard or waterfall → **Drill through → Category Detail**. The back arrow returns.
* **Tooltip:** hover a month on a trend line to see the Month snapshot card.
* **Filters:** the four sidebar slicers are synced across all pages. RFM figures are lifetime values, so the Year slicer does not change them (Region, Channel and Segment do).
